# BB84 Quantum Cryptography Simulator

An interactive, web-based visual walkthrough demonstrating the **BB84 quantum key distribution (QKD)** protocol, built using HTML5 Canvas, modern CSS, and vanilla JavaScript.

## Features
- **Live Photon Simulation:** Visualizes photons traveling through a quantum channel.
- **Eavesdropper Toggle (Eve):** Dynamically introduce an interceptor to observe quantum state collapse and error injection.
- **Sifting Phase:** Step-by-step breakdown of matching bases and key generation.
- **Security Verdict:** Real-time error rate tracking to flag compromised channels.

## Technologies Used
- HTML5 / CSS3 (Custom properties, grid layouts)
- JavaScript (Async loops, canvas animation)
